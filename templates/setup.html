2. Connect TMDb

cinematix uses The Movie Database to search movies and show posters. The key is free:

  1. Create an account at themoviedb.org.
  2. Open Settings → API and request a key for personal use.
  3. Copy the "API Key" or the "API Read Access Token" and paste it here.

{{ errors.tmdb_api_key or '' }}

3. Get notifications

cinematix sends push notifications through ntfy, a free app for Android and iPhone. A private topic was made for you:

  1. Install the ntfy app on your phone.
  2. In the app, tap + and enter the topic name . Or scan the code to open the topic in the phone's browser.
  3. Tap Send test and check that the notification arrives.

{{ errors.ntfy_endpoint or '' }}

Anyone who knows the topic name can read it, so keep it private. A self-hosted ntfy server works too: enter its topic URL.
